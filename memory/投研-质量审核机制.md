# 质量审核与打回重做机制

## 审核覆盖

投资领导（Agent7）对所有Agent的输出进行结构化质量审核，每个Agent有专属审核标准：

| Agent | 审核项数 | 核心检查 |
|-------|---------|---------|
| 🕵️ 情报员 | 6项 | 大盘概况、板块热点、资金流向、政策要闻、长度、数据来源 |
| 📊 分析师 | 5项 | 技术指标、板块排名、均线分析、趋势结论、长度 |
| 🔍 选股机器人 | 5项 | 候选列表、多因子评分、推荐结论、持仓冲突、否决记录 |
| 🛡️ 风控官 | 5项 | 止损检查、仓位检查、风控等级、操作指令、操盘审查 |
| 🎯 操盘手 | 5项 | 买入清单、卖出清单、止损位、仓位汇总、风控合规 |

## 审核结果

- ✅ **通过**（PASS）— 正常纳入最终决策
- ⚠️ **需补充**（NEEDS_REVIEW）— 建议打回补充，附带改进要求
- ❌ **不合格**（REJECTED）— 必须打回重做，附带具体改进要求

## 打回重做流程

```
审核发现不合格 → 生成打回指令（附改进要求）→ Agent收到后补充
→ 在报告末尾添加 #REWORKED 标记 → 投资领导重审 → 通过/跳过
```
