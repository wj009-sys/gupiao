# 交易执行规则 — 操盘手使用

## 买入规则

### 建仓原则
1. **分批建仓**：单票分2-3次买入，每次间隔≥1天（或价格间隔≥2%）
2. **仓位分配**：首次建仓 ≤ 目标仓位的50%，确认趋势后加仓
3. **价格区间**：买入必须在指定价格区间内，超出区间不追高
4. **时间选择**：优先尾盘（14:30后）买入，避开开盘波动

### 买入条件（需要同时满足）
- 选股机器人评分 ≥ 65（推荐级别）
- 风控官风险等级 ≠ HIGH
- 当前价格在建议买入区间内
- 当日非个股放量下跌

## 卖出规则

### 止盈规则
- **目标止盈**：达到目标价+15%~+20%时，分批止盈
  - 第一次：达到+15%，卖出1/3
  - 第二次：达到+20%，卖出1/3
  - 剩余：移动止盈，回撤-5%时清仓
- **移动止盈**：盈利超过+10%后，从最高点回撤-5%即卖出

### 止损规则（参考止损规则.json）
- **固定止损**：亏损达-7%强制止损
- **时间止损**：买入后5个交易日未达预期，减半仓
- **大盘联动**：大盘破20日线，减半仓；破60日线，清仓

### 调仓规则
- **替换**：如果找到评分更高的票（≥当前持仓票评分+10），可替换
- **减仓**：单票超过仓位上限，减至上限以内
- **清仓**：风控等级变为HIGH时，检查所有持仓是否需要清仓

## 仓位管理

### 仓位分配原则
1. **核心持仓**（50%）：2-3只基本面优质票，中线持有（1-3个月）
2. **卫星持仓**（30%）：2-3只趋势票，短线操作（1-4周）
3. **现金**（≥20%）：保持流动性，应对机会/风险

### 再平衡
- 每周检查一次仓位比例，偏离目标超过10%时调整
- 单票利润超过总资产5%时，考虑部分止盈

## 交易日志规范

每笔交易计划必须包含：
```
买入/卖出: 股票名称(代码)
方向: 买入/卖出/持有
数量: XXX股（或XX%仓位）
价格区间: XX.XX - XX.XX
理由: [引用的Agent报告+数据]
止损/止盈: XX.XX（-7%）
优先级: 高/中/低
```

## 📋 D3 异常场景

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 分时价格超出指定价格区间 | 等待价格回落至区间内，否则放弃该笔买入 | 标注"未成交"，移至观察池 |
| 大盘盘中突发利空（跌破关键均线） | 触发大盘联动止损，减半仓或清仓 | 按大盘规则执行，不等个股信号 |
| 移动止盈价高于当前价（最高点在更早日期） | 用当日最高价重新计算回撤水平 | 降级为固定止盈+15%，锁定已有利润 |
| 分批买入第一笔后股价反转下跌 | 等待触发止损线（-7%）前不出第二笔 | 触发止损则清仓，不补仓 |
| 时间止损票突然放量拉升 | 重新评估，如果是有效放量突破可继续持有 | 按原规则减半仓，保留部分仓位 |
| 仓位计算时总资产字段为None | 依次用总资产_含现金 → 持仓总市值 → 估算值 | 标注"仓位估算"，使用保守值 |

## 🔴 D4 检查点

- [ ] **分批买入节奏**：首次建仓 ≤ 目标仓位50%，确认趋势后再加仓
- [ ] **止损必设**：每笔买入必须设置止损位（-5%~-7%）
- [ ] **风控优先**：风控等级HIGH时，所有买入建议自动取消
- [ ] **仓位上限追溯**：区分总仓位上限和单票上限，不能混淆（Darwin D4）
- [ ] **涨跌停范围**：买入价格不得超出当日涨跌停价
- [ ] **尾盘优先**：买入时间优先14:30后，开盘前15分钟不操作
- [ ] **仓位再平衡**：每周偏离目标超过10%时调整

## ⛔ D9 工作反例

| # | 错误做法 | 为什么 | 正确做法 |
|---|---------|-------|---------|
| 1 | 逆势加仓（越跌越买） | 趋势下跌时加仓放大亏损 | 止损出局，等企稳确认再进场 |
| 2 | 开盘前15分钟内追涨 | 开盘波动最大，容易被假突破骗线 | 尾盘（14:30后）买入 |
| 3 | 不止损死扛 | 单票-7%不止损可能扩大到-30%+ | 触发-7%无条件执行止损 |
| 4 | 止损后立即买回 | 刚被止损说明判断错误 | 至少等3个交易日重新评估 |
| 5 | 满仓过业绩披露期 | 一个财报暴雷就重创 | 业绩期控制仓位≤60% |
| 6 | 借贷/杠杆投资 | 杠杆放大亏损速度，心态崩塌 | 只用闲置资金，不加杠杆 |
