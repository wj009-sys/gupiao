# 数据源优先级策略

> 用途：定义各数据域的主/备/兜底数据源优先级，减少重复API调用，规避IP封禁风险。
> 维护者：全员 | 最后更新：2026-07-05

---

## 核心原则

1. **本地DB优先** — 所有Agent优先读取 `data/stocks.db` 中已缓存的数据
2. **免费源优先** — 同等条件下优先使用免费的 a-stock-data 源，节约Tushare API配额
3. **限流共享** — 所有东财API调用通过 `scripts/utils/_proxy.rate_limited_get()` 全局协调
4. **Token降级** — Tushare Token缺失时，`tushare_client.py` 不崩溃，所有API返回空DataFrame

## 限流策略

```
东财系全部API (push2/push2ex/emappdata/datacenter-web):
  ✓ 共享 scripts.utils._proxy.rate_limited_get() 网关
  ✓ 全局串行化：跨模块最小间隔 1.1s
  ✓ SOCKS_PROXY 代理（settings.local.json 配置）
  ✓ 403时自动退避60s

Tushare:
  ✓ 200次/min 上限（tushare SDK 自带）
  ✓ Token缺失时降级到 data_provider.py 多源fallback

同花顺 (10jqka):
  ✓ 单次接口延迟低(~73ms)，无已知封禁
  ✓ 调用频率建议 < 5次/s

腾讯财经 (qt.gtimg.cn):
  ✓ 实测稳定不封IP
  ✓ 单次最多30只股票
```
