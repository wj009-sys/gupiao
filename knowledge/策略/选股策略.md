# 选股策略 — 选股机器人使用

> 最后更新：2026-07-04（达尔文9.0：5因子→8因子升级，新增流动性/稳定性/反转因子，评分曲线可配置化）
> 关联：[[ZhuLinsen三项目借鉴分析]]、[[TradingAgents借鉴分析]]

## 核心理念

多因子选股，不依赖单一指标。每个候选票必须经过至少3个维度交叉验证。

## 因子体系（8因子，借鉴AlphaSift screen_score）

### 8因子权重总表

| 因子 | 早盘 | 盘中 | 午盘 | 晚间 | 含义 |
|:-----|:---:|:---:|:---:|:---:|:-----|
| 📊 估值 | 12% | 0% | 12% | 18% | PE/PB估值吸引力 |
| 📈 成长 | 12% | 5% | 12% | 15% | 营收/净利/ROE增长 |
| 🔄 动量 | 20% | 20% | 15% | 12% | 短期/中期趋势强度 |
| 🔥 情绪 | 15% | 30% | 20% | 10% | 资金流向/市场情绪 |
| 📐 技术面 | 12% | 15% | 12% | 12% | 均线/量价/技术指标 |
| 💧 **流动性** ⭐ | 10% | 10% | 10% | 12% | 成交额+换手率（新增） |
| 🛡️ **稳定性** ⭐ | 9% | 10% | 9% | 10% | 波动惩罚+过热控制（新增） |
| 🔄 **反转** ⭐ | 10% | 10% | 10% | 11% | 回撤修复机会（新增） |

> **新增因子说明**：
> - **流动性因子**：成交额log平滑 + 换手率理想中间值曲线（非简单线性）
> - **稳定性因子**：从满分85分开始扣减（单日涨跌过大、换手过热、负PE、波动率过高）
> - **反转因子**：回撤-3%~-8%为最优反转区域，结合企稳信号（缩量/RSI回升）
> - 所有新增因子使用非线性评分曲线（scoring_profile可配置）

## 评分曲线配置（scoring_profile）

借鉴AlphaSift的非线性评分设计，关键曲线参数可在 `data/选股规则.json` 中配置：

```json
{
  "scoring_profile": {
    "momentum_chase_start_pct": 12.0,
    "activity_ideal_volume_ratio": 1.8,
    "activity_ideal_turnover_rate": 5.0,
    "reversal_ideal_change_pct": -3.0,
    "stability_hot_change_pct": 9.0,
    "stability_extreme_volume_ratio": 5.0
  }
}
```

## 风险叠加层（Risk Overlay）

独立于因子评分的惩罚/否决机制（见 `scripts/utils/risk_overlay.py`），包含：

| 检查项 | 触发条件 | 动作 |
|:-------|:---------|:-----|
| 单日涨跌过大 | >9% | 惩罚；>11%否决 |
| 量比异常 | >5 | 惩罚 |
| 负PE | PE<0 | 惩罚-20分 |
| MACD弱势 | diff<0且dea向下 | 惩罚 |
| 高PB | PB>10 | 惩罚 |
| 连跌 | 连跌3天+ | 惩罚 |

### 1. 估值因子（权重随模式变化）
- **PE（市盈率）**：0 < PE < 80，且低于行业平均的1.5倍
- **PB（市净率）**：0 < PB < 10，破净股（PB<1）需额外关注
- **PE历史分位**：当前PE处于近5年历史分位的70%以下（即不在历史高位）
- **PS（市销率）**：可选参考，成长型公司可放宽PE限制

### 2. 成长因子（权重随模式变化，见上表）
- **营收增长**：近2个季度营收同比增长率 > 10%
- **净利润增长**：近2个季度净利润同比增长率 > 15%
- **ROE**：> 8%（连续2年）
- 注：财报数据有延迟，季度末可使用预告数据

### 3. 动量因子（权重随模式变化，见上表）
- **短期动量**：近20个交易日涨幅在[-5%, +30%]之间（排除涨幅过高的追涨票）
- **中期趋势**：近60日涨幅 > 近20日涨幅（趋势未结束）
- **相对强度**：相对于大盘（沪深300）近20日超额收益 > 0

### 4. 情绪因子（权重随模式变化，见上表）
- **北向资金**：近3日北向资金净流入该股所在板块
- **主力资金**：近5日主力资金净流入
- **龙虎榜**：近5日有机构席位买入优先（无龙虎榜数据时不扣分）

### 5. 技术面因子（权重随模式变化，见上表）
- **均线排列**：5日 > 10日 > 20日 > 60日（多头排列）得分最高
- **MACD**：零轴上方金叉 > 零轴上方 > 零轴下方金叉 > 零轴下方
- **KDJ**：K线在20-80之间上行，J线不高于100（不超买）
- **成交量**：近3日成交量 > 前5日均量30%（放量突破）

## 持仓冲突规则

- 推荐股票所在行业 + 现有持仓同行业占比 ≤ 40%
- 推荐股票若与持仓同属一个行业，必须比持仓中的同行业股票在至少2个因子上更好

## 输出格式

每只候选票输出：
```
[评分] 股票名称(代码)
  估值分: XX | 成长分: XX | 动量分: XX | 情绪分: XX | 技术分: XX | 流动性分: XX | 稳定性分: XX | 反转分: XX
  入选理由: ...
  买入区间: XX-XX
  止损位: XX（-7%）
  风险提示: ...
```

## 🚨 D3 异常处理表

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| PE/财务数据缺失（财报未更新） | 用前季数据或预告数据代替，标注"数据滞后X个月" | 估值因子0分，不参与总分计算 |
| 板块与行业匹配失败（同花顺概念板块名称变更） | 用模糊匹配（包含关键词）或手动映射表 | 跳过板块动量因子，标注"板块分类失败" |
| 北向资金/主力资金无数据 | 检查数据日期是否为非交易日 | 情绪因子以技术面为主，降低资金流向权重 |
| 龙虎榜数据3日无更新 | 延长查询周期至5日 | 跳过龙虎榜加分，不扣分 |
| 停复牌数据接口异常 | 用daily接口检查当日是否有日线数据 | 标注"停牌状态未知"，保守不推荐 |

> **核心原则：模式选错则评分全废。早盘看隔夜+停牌，盘中看资金+异动，午盘看半日+方向，晚间看全天+复盘偏差。**

## 🔴 D4 检查点

- [ ] **数据时效检查**：使用的财务数据是否最新？超过6个月需降级
- [ ] **8因子独立性验证**：成长因子不能与动量因子共用计算逻辑；流动性/稳定性/反转因子各自独立计算（Darwin D4+D9）
- [ ] **流动性因子数据可用性**：成交额/换手率数据是否齐全（非停牌日）
- [ ] **稳定性因子边界检查**：极端波动惩罚上限不应超过-20分（防止单一因子主导）
- [ ] **反转因子信号确认**：回撤-3%~-8%是理想反转区，超出-15%需标注"深度回撤风险"
- [ ] **风险叠加层检查**：risk_overlay 的6项惩罚项是否已全部执行，否决项是否已排除
- [ ] **持仓冲突检查**：推荐股票与现有持仓同行业占比 ≤ 40%
- [ ] **停复牌前检查**：所有推荐标的必须排除当日停牌股票
- [ ] **ST/退市过滤**：ST、*ST、退市整理期股票一律排除
- [ ] **涨跌停范围检查**：建议买入价必须在当日涨跌停范围内
- [ ] **复盘偏差引用**：evening模式必须读取复盘报告的因子调整建议（双向反馈）

## ⛔ D9 工作反例

| # | ❌ 错误做法 | 为什么 | ✅ 正确做法 |
|---|-----------|-------|-----------|
| 1 | 早盘用晚间权重 | pre_market和evening模式的外部环境完全不同 | 4种模式对应独立权重配置 |
| 2 | 盘中看估值 | 盘中数据接口不返回PE/PB，估值因子必然为0 | 盘中模式跳过基本面，侧重资金+量价 |
| 3 | 不看复盘偏差 | 复盘报告的调整建议是最新的学习成果 | even模式必须读取复盘报告中的因子调整 |
| 4 | 已持仓股票再推荐 | 重复推荐浪费候选名额 | 推荐前检查持仓列表，排除已有持仓 |
| 5 | 成长因子用动量冒充 | 两因子相关性高但逻辑不同 | 营收增速+净利增速+ROE独立计算 |

## 🔄 与复盘师联动

复盘师（Agent4）每晚复盘时会检查选股因子的表现：
- 因子准确率 < 40% → 下调权重建议写入复盘报告
- 选股机器人需在evening模式读取复盘报告的因子调整建议
