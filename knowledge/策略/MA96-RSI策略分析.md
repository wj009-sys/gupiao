## 二、核心发现：96这个数字从哪里来？

### 起源：5分钟K线

MA96 在 A 股民间技术派中确实存在，但主流用法是 **5分钟K线** 而非日线：

```
5分钟K线:  96根 × 5分钟 = 480分钟 = 8小时 = 2个交易日
```

所以在5分钟级别，MA96 = **2日线**，作为日内做T的支撑/压力参考。

### 日线级别：非标准参数

| 周期 | 时间跨度 | 说明 |
|:----|:--------|:----|
| MA20 | ≈ 1个月 | ✅ 月线，A股最常用短期均线 |
| MA60 | ≈ 1季度 | ✅ 季线，中期趋势分水岭 |
| **MA96** | **≈ 4.5个月** | ⚠️ 非常规，介于季线和半年线之间 |
| MA120 | ≈ 半年 | ✅ 半年线，牛熊分界线 |
| MA250 | ≈ 1年 | ✅ 年线，长期牛熊线 |

**结论：96无特殊统计意义，只是5分钟K线的"遗产"。**

**反直觉发现**：放量拉升后的卖出信号正确率反而更低——放量意味着趋势强劲，此时卖出容易踏空后续涨幅。反倒是**缩量大阳线远离均线**时卖出更靠谱（动量衰竭信号）。

## 五、这个策略的本质

你描述的这套策略，本质上是一个 **「均线回归」+「RSI极值」** 的策略：

```
    趋势判断：           MA120方向
    买入信号：  价格回归MA120 + RSI超卖(<30)
    卖出信号：  价格远离MA120 + RSI超买(>70)
    量能过滤：  缩量确认支撑 + 放量确认突破（但卖出时慎用）
```

### 适用市场环境
- ✅ 震荡市（价格围绕均线上下波动）→ 最佳
- ✅ 温和上涨趋势（有回踩均线的机会）
- ❌ 单边暴涨（价格永远远离均线，永远买不到）
- ❌ 单边暴跌（MA120是纸糊的，不断被跌破）

### 建议实施参数（基于回测数据）

| 参数 | 推荐值 | 原因 |
|:----|:------|:----|
| 均线周期 | **MA120** ← 不是96 | 回测最优 |
| RSI周期 | 14 | 系统自带，已足够 |
| RSI买入阈值 | < 30 | 标准超卖区 |
| RSI卖出阈值 | > **75**（不是70） | 避免在震荡中被震出 |
| "在均线附近" | 价格在MA120的**±2%**内 | 太宽则信号质量下降 |
| "远离均线" | 价格超过MA120的**+5%** | 配合RSI>75使用 |
| 买入量能确认 | 缩量（量比<0.8）为加分项 | 信号太少不强制 |
| 卖出量能确认 | 不放量即可 | 放量反而趋势强劲 |

## 六、最终建议 — 修正版（含退市股）

### ✅ 这个策略可行的部分（结论不变）

1. **"RSI<30在均线附近是买入信号"** → ✅ 含退市股后胜率61-64%，仍然有效
2. **"RSI>70远离均线是卖出信号"** → ✅ 有效，但阈值需提高到75
3. **你描述的价格行为规律** → ✅ 缩量回踩、放量拉升的判断方向正确

### ❌ 需要修正的部分（因退市股而更关键）

1. **96日线 → 120日线** — 含退市股后MA120仍然优于MA96
2. **RSI>70就卖 → RSI>75** — 减少假信号
3. **放量拉升不卖** — 放量意味着趋势强劲，卖出太早
4. **⚠️ 必须加止损！** — 含退市股后这个策略最大的风险是**抄底退市股**
   - 策略会在退市股每次暴跌中反复触发买入（RSI<30 + 靠近均线）
   - 如果没有止损会不断抄底→亏损→再抄底→更亏

### 🛡️ 修正后的策略框架（含止损）

```
买入：价格缩量回踩MA120(半年线) + RSI(14) < 30  → 建仓
加仓：价格在MA120附近企稳 + RSI拐头向上        → 加仓

减仓：价格远离MA120 > 5% + RSI > 75            → 减1/3
清仓：价格远离MA120 > 8% + RSI > 80            → 清仓

止损：价格跌破MA120 > 3% + RSI仍在<40          → 坚决止损 ← 新增！

反例：不要连续补仓！RSI<30在退市股上可能持续数月
      → 如果买入后5日未脱离均线，减半仓
      → 如果买入后跌破MA120超过5%，清仓，不补仓
```
