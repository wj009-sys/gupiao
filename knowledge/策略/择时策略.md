# 择时策略 — 入场/出场时机判断

> 参考文档：`data/策略规则.json`（买入/卖出策略）、`data/止损规则.json`（止损参数）
> 来源：《投研团队设计方案.md》知识库规划

## 核心理念

**选股解决"买什么"，择时解决"什么时候买/卖"。** 再好的股票，买在错误的时间也会亏损。
择时的核心是识别市场情绪周期和资金流向的拐点。

---

## 一、大盘择时

### 趋势跟踪（中长期）

| 信号 | 动作 | 胜率条件 |
|------|------|---------|
| 大盘站上20日线 + 5日线金叉20日线 | 加仓至上限80% | 需伴随放量 |
| 大盘在20-60日线之间震荡 | 震荡市模式（≤80%仓位） | 高抛低吸 |
| 大盘跌破20日线 | 减仓至50%以下 | 无条件执行 |
| 大盘跌破60日线 | 清仓或保留≤10%对冲仓位 | 无条件执行 |

### 动量择时（中短期）

- **大盘RSI(14) < 30 且出现底分型** → 超卖反弹机会，可加仓
- **大盘RSI(14) > 70** → 超买区域，减仓锁定利润
- **大盘成交量 < 前5日均量50%** → 缩量底部区域，可逐步建仓
- **大盘成交量 > 前5日均量200% + 阴线** → 放量下跌，清仓回避

### 情绪择时

- **两市成交额 < 5000亿** → 市场极度冷清，不宜重仓
- **两市成交额 > 1.2万亿** → 市场活跃，可积极操作
- **涨停家数 < 20家 + 跌停 > 10家** → 情绪冰点，等待反转信号
- **涨停家数 > 80家** → 情绪高潮，警惕短期见顶

## 二、个股择时

### 入场时机

| 条件 | 说明 | 优先级 |
|------|------|-------|
| **尾盘买入**（14:30-14:55） | 避开盘中波动，当天风险已释放 | ⭐ 首选 |
| **放量突破压力位** | 价格放量站上20日线或前高 | ⭐ 首选 |
| **回调不破支撑** | 缩量回踩10日/20日线不破 | 优先 |
| **分时均线附近** | 盘中价格回踩分时均线企稳 | 次选 |
| **开盘急跌-3%~-5%** | 恐慌性低开，有修复预期的强势股 | 谨慎（控制仓位） |

### 出场时机

| 条件 | 说明 | 优先级 |
|------|------|-------|
| **触及止损线**（-7%） | 无条件执行，不抱幻想 | 🔴 强制 |
| **达到止盈目标**（+15%~+20%） | 分批止盈：+15%出1/3，+20%出1/3 | 🟢 推荐 |
| **移动止盈**（盈利>10%后回撤-5%） | 保护利润，从最高点回撤-5%清仓 | 🟢 推荐 |
| **大盘破位** | 大盘触发减仓/清仓信号时联动 | 🟡 联动 |
| **时间止损**（买入后5日不达预期） | 减半仓，避免资金无效占用 | 🟡 可选 |

## 三、特殊场景择时

### 业绩披露期
- **财报前1周**：不建新仓，已有持仓视预期而定
- **财报超预期高开**：不追，等3天回落确认后再考虑
- **财报暴雷低开**：开盘立即止损，不博反弹

### 节假日效应
- **长假前3天**：逐步减仓（节前资金外流）
- **长假后首日**：不买入，观察1天确认方向

### 政策窗口期
- **重要会议期间**：市场以维稳为主，降低操作频率
- **政策超预期**：涉及板块可追（不追个股），ETF优先
- **政策低于预期**：相关板块回避，已有仓位减仓

## 五、反例（不要这样做）

| ❌ 错误做法 | 为什么 | ✅ 正确做法 |
|------------|--------|------------|
| 开盘前15分钟买入 | 开盘波动最大，容易被假突破骗线 | 尾盘（14:30后）买入 |
| 放量下跌时抄底 | 下跌放量说明抛压未释放完 | 等缩量企稳再考虑 |
| 利好出公告后追高 | 消息已被消化 → 高开低走 | 等回落企稳再入场（或放弃） |
| 止损后又立即买回 | 刚被止损说明判断错误 | 至少等3个交易日重新评估 |
| 满仓过业绩披露期 | 一个暴雷就重创 | 业绩期控制仓位≤60% |
