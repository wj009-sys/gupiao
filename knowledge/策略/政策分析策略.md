## 一、政策分类框架

### 四级分类体系

| 类别 | 子类 | 典型来源 | 市场影响速度 | 影响时长 |
|:----|:-----|:--------|:-----------|:--------|
| **宏观调控** | 货币政策(利率/准备金/MLF)、财政政策(赤字/专项债/基建)、汇率政策 | 央行、国务院、财政部 | 即时~1周 | 1-3月 |
| **产业政策** | 行业扶持(补贴/税收优惠)、限制(产能/环保/准入)、发展规划(十四五/专项规划) | 发改委、工信部、能源局 | 1周~1月 | 3-12月 |
| **监管动态** | 证监会规则、交易所指引、立案调查、退市、IPO节奏、减持新规 | 证监会、交易所 | 即时~1天 | 1-6月 |
| **税收政策** | 增值税/所得税调整、印花税、关税、减免税 | 财政部、税务总局 | 1天~1月 | 6-12月 |

### 政策阶段影响差异

同一条政策在不同阶段的确定性/影响力差异巨大：

```
吹风/传闻 → 草案征求意见 → 审议通过 → 正式实施
影响力: 低        中              高           极高(兑现)
确定性: 差        中              高           确定
```

## 二、政策影响力评估方法

### 评估维度

| 维度 | 评分 | 说明 |
|:----|:----|:------|
| 政策层级 | 宏观+3 / 产业+2 / 监管+2 / 税收+1 | 越宏观影响越广 |
| 实施确定性 | 已实施+3 / 审议通过+2 / 征求意见+1 / 传闻+0 | 确定性越高可信度越高 |
| 市场预期差 | 超预期+3 / 符合预期+0 / 低于预期-2 | 预期差决定市场反应 |
| 影响范围 | 全市场+3 / 行业级+2 / 个股级+1 | 范围越广波动越大 |
| 时效紧迫性 | 立即执行+2 / 未来执行+1 / 长期规划+0 | 越紧迫短期影响越大 |

### 影响评分（Impact Score）

- **+5 重大利好**：降准降息、大规模财政刺激、行业全面扶持
- **+3 明显利好**：产业补贴、减税、监管放松
- **+1 轻微利好**：中性政策偏正面解读、规划性质文件
- **0 中性**：常规性通知、无实质影响
- **-1~-5 利空**：对称于利好评分

### 政策→板块映射关系

| 政策类型 | 利好板块 | 利空板块 |
|:--------|:--------|:--------|
| 降准降息 | 银行、地产、券商、高股息 | 银行(净息差压缩) |
| 基建投资 | 建筑、建材、工程机械 | — |
| 地产松绑 | 房地产、家装、银行 | — |
| 新能源扶持 | 光伏、风电、锂电、储能 | 传统能源 |
| 芯片扶持 | 半导体、设备、材料 | — |
| 监管收紧 | — | 互联网、金融科技、小市值 |
| 加税/关税 | — | 出口依赖型行业 |
| 环保限产 | 新能源、环保设备 | 高耗能行业(钢铁/化工) |

## 三、持仓关联分析

### 关联规则

1. **直接关联**：持仓股票所属板块与政策影响板块一致 → 直接影响
2. **间接关联**：持仓股票的上下游/竞争对手受政策影响 → 间接影响
3. **宏观关联**：宏观政策影响整体市场流动性/风险偏好 → 系统性影响

### 影响程度划分

| 程度 | 标准 | 行动建议 |
|:----|:-----|:--------|
| 高 | 政策直接作用于持仓行业，且影响评分≥+3或≤-3 | 重点分析，考虑调仓 |
| 中 | 政策间接影响或影响评分±1~±2 | 关注但不急于行动 |
| 低 | 宏观层面的系统性影响或影响评分0 | 纳入决策参考但不单独行动 |

## 四、与其他策略的联动

### 择时联动

- 重大利好政策出台后 → 可适当放宽择时标准
- 监管收紧/利空政策 → 严格执行止损，降低仓位

### 选股联动

- 政策扶持行业 → 选股因子中加入政策加分
- 政策打压行业 → 短期规避，即使技术面信号好也谨慎

## 五、分析流程

```
读取政策新闻 → 分类(宏观/产业/监管/税收)
    → 判断阶段(吹风/草案/实施)
    → 评估影响方向(利好/中性/利空)
    → 匹配影响板块
    → 关联到持仓
    → 输出影响程度(高/中/低)
    → 写入 policy_events 表
```
